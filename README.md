# 小布建议双栏自定义

把 OPPO / 一加「小布建议」桌面小组件的**左右两栏**换成任意卡片。

系统原本只允许在「系统工具 + 应用建议」这类固定组合里挑卡；本模块借用系统自带的
**「编辑默认样式」**界面，让你把左栏、右栏分别换成卡片池里的任意一张卡
（原生卡 / 快应用卡 / 系统工具卡），并支持两栏对调。**不新增任何自己的 UI。**

## 环境

| 项 | 要求 |
|---|---|
| 系统 | ColorOS 17 / Android 17（已在 `PLG110_17.0.0.105(CN01)` 验证） |
| 框架 | LSPosed 2.1.1+ |
| 注入进程 | 仅 `com.oplus.pantanal.ums`（决策引擎），不注入桌面 |

## 安装

1. 安装 APK，在 LSPosed 管理器里启用模块（作用域由模块指定，无需手动勾选）；
2. 在 LSPosed 的作用域列表里长按「**智慧建议服务**」→ **强行停止**，让决策进程重新加载模块；
3. 回到桌面，长按卡片 → **编辑默认样式** → 切到多出来的自定义页签。

## 使用

```
长按卡片 → 编辑默认样式 → 自定义页签
  → 点预览里的「左栏」或「右栏」→ 开始编辑
  → 在卡片池里选一张卡 → 完成
```

- 两栏独立：只改一栏不影响另一栏；
- **两栏对调**：分别给两栏选中对方的卡并保存即可，桌面会短暂显示系统卡随后换栏；
- 想恢复原样：切到系统页签保存即可，模块配置会保留。

## 常见问题

**改完没生效？**
确认第 2 步做过（强行停止「智慧建议服务」）。模块在进程启动时加载，决策进程不重启就还是旧代码。

**对调后看不到变化？**
对调时请停留在小组件所在的那一页，桌面才会立即刷新。

## 已知限制

- 只在上述 ROM 上验证过，系统版本更新后可能需要适配；
- 两栏不能选同一张卡（宿主会丢弃整个组合）；
- 对调过程中会短暂显示系统卡。
