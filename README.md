# 小布建议双栏自定义

把 OPPO / 一加「小布建议」桌面小组件的**左右两栏**换成任意卡片。

系统原本只允许在「系统工具 + 应用建议」这类固定组合里挑卡；本模块借用系统自带的
**「编辑默认样式」**界面，让你把左栏、右栏分别换成卡片池里的任意一张卡
（原生卡 / 快应用卡 / 系统工具卡），并支持两栏对调。**不新增任何自己的 UI。**

## 环境

| 项 | 要求 |
|---|---|
| 系统 | ColorOS 17 / Android 17（已在 `PLG110_17.0.0.105(CN01)` 验证） |
| 框架 | LSPosed 2.1.1+ |
| 注入进程 | 仅 `com.oplus.pantanal.ums`（决策引擎），**不注入桌面** |

## 安装

1. 安装 APK，在 LSPosed 里启用模块（作用域由模块静态声明，正常无需手动勾选）；
2. **重启决策进程**，否则跑的还是旧 dex：

   ```
   su -c 'am force-stop com.oplus.pantanal.ums'
   ```

3. 回到桌面，长按卡片 → **编辑默认样式** → 切到多出来的「系统工具+xxx」页签。

## 使用

```
长按卡片 → 编辑默认样式 → 自定义页签
  → 点预览里的「左栏」或「右栏」→ 开始编辑
  → 在卡片池里选一张卡 → 完成
```

- 两栏独立：只改一栏不影响另一栏；
- **两栏对调**：保存后桌面会先闪约 1 秒系统卡再互换 —— 这是触发桌面重排的唯一可行手段，
  属机制固有，不是 bug；
- 想恢复原样：切到系统页签保存即可，模块配置会保留。

## 已知限制

- **只在上述 ROM 上验证过**。所有钩子绑定当前 ROM 的类名/方法名，系统更新后可能需要重新适配；
- 两栏不能选同一张卡（宿主会丢弃整个组合）；
- 对调时无法做到零闪（零闪方案尝试过并已放弃）。
